## Findings considered and rejected

- **"`not_configured` and `http_error` show no banner":** wrong. `http_error` maps to
  status `error`, which has a banner (`public/app.js:114`), and `not_configured` is
  covered by the `keyConfigured` banner (`public/app.js:106`).
- **Non-atomic KV sync lock:** KV has no compare-and-set. Merging by activity id makes a
  rare double sync harmless. Documented in plan 005 as best-effort, not fixed.
- **Stats performance:** `computeStats` makes about 30 passes over about 460 runs, which
  takes milliseconds. Not worth optimizing.
- **Deletions on Garmin are not mirrored:** an inherent limit of incremental syncing,
  acceptable for a personal dashboard. Recorded in plan 005's maintenance notes.
- **Shared status vocabulary between `src/sync.js` and `public/app.js`:** the duplication
  is real but cosmetic now that no status lacks a banner. Deferred.
- **`npm audit`:** 0 vulnerabilities at audit time.
